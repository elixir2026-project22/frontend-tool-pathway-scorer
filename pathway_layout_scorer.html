Scoring rules

Each rule is measured from the node and line coordinates in the file. A rule scores 100 at its pass threshold and 0 at its fail threshold, with a linear scale in between. Required rules count twice in the overall score, recommended rules once. All thresholds and weights can be changed under Scoring settings.

Reproducibility, fixed node positions, versioning and interoperable output depend on the layout tool rather than on a single map, so they are not scored here. Check them by running a tool twice on the same input and comparing the two results.

Supported file formats

The format is recognised from the file content, so the extension does not matter (.sbgn, .xml, .sbml, .json or none).

SBGN-ML

Process Description maps, versions 0.2 and 0.3. Glyph boxes, arcs with bend points and clone markers are all read.

SBML with Layout

SBML Level 3 with the Layout package, or Level 2 with the layout annotation. Line curves are read; species drawn more than once count as cloned.

SBML from CellDesigner

SBML Level 2 with CellDesigner annotations. Node positions are read; lines are treated as straight, so bends are not counted.

Escher JSON

Escher map files. Metabolite and reaction marker positions and curved segments are read; reaction direction comes from the stoichiometry.

About

This scorer was developed during the BioHackathon 2026 project on the evaluation and automation of metabolic pathway map layouts. The group defined a set of hard and soft layout rules for readable metabolic maps; this page turns each rule into a measurement so that hand-drawn reference maps and automatic layouts can be compared on equal terms.

The measurements are the same as those of the project's Python script score_rules.py, so results from both can be combined. The cofactor list and the thresholds are first proposals and are expected to change as the group tunes them.

The example maps come from the Metabolism Regulation gallery and are available under CC0.

Scoring settings

Metabolite names separated by commas, for example the TCA cycle. Leave empty to use the largest cycle of four or more metabolites found in the map.

Names separated by commas or line breaks, not case-sensitive. These count as cofactors for the clone rule and are left out when looking for cycles.
